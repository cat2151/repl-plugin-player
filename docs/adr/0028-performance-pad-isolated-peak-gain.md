# ADR 0028: try pad の増幅量は発音中に補正し、次の発音で見直す

- 状態: 採用（増幅開始までの時間と増幅量の閾値は暫定）
- 決定者: user（単音でも和音でも小さい音は発音中に補正し、次に小さい音を鳴らしたときは増幅の上限を見直す。リリースの減衰では増幅を上げず、最終出力をリミッターで保護する）。増幅を始めるまでの時間と閾値は AI の設計。
- 関連: [ADR 0025](0025-evolve-loudness-trim-and-limiter.md)

## 決定と理由

try pad の auto gain は、当初は最終ミックスのラウドネスを測っていた。楽器を替えながら演奏すると、前の楽器や他トラックの音も同じ補正に入るため、静かなインスタンスだけを持ち上げられない。インスタンスの出力を常に計測する方法でも、連打で前のリリースが重なると、単発の音より大きいピークで補正が決まる。

リリースの重なりを除くため、当初は前の音と重ならずに始まり、計測中に追加のノートが来なかった単音を採用した。採用した単音のうち最大のサンプルピークをセッション中保持し、最初の測定が確定するまでは等倍で鳴らした。

オフラインで試奏して測る案では、ユーザーが選ぶ音域やパラメーター値を試奏条件として先に決める必要がある。ライブ計測なら実際に鳴らした音が基準になる。ドラムは複数のパッドが同じインスタンスを鳴らすため、一つの補正を共有する。

発音前と離鍵後の両方で −80 dBFS 未満を求めたところ、一部の音色で確定待ちが終わらないと user から報告があった。長いリリースや常時ノイズで止まることを再現し、背景音を許容して離鍵後の計測を最大２秒に制限した。

和音から弾き始めると、２音目で候補を破棄するため、離鍵後の時間上限があっても計測待ちは終わらなかった。単音でも離鍵まで小さいまま鳴る。user が求めているのは演奏中に素早く適切な音量に近づくことであり、ピークを保持する目的は減衰に合わせて増幅が上がるのを防ぐことだと判断し、確定待ちを廃止した。

発音から約 40 ms 観測し、単音・和音とも補正前のピークに応じて増幅を始める。ピークが上がったときはすぐに増幅を抑え、同じ発音の間は最大ピークを保持する。全キーを離した後は増幅を上げない。次の発音でピークを見直すので、和音のあとに小さい単音を弾いても増幅を上げ直せる。ただし和音の余韻に重ねて弾いた単音は、余韻のピークを保持して押し続けても小さいままになることを実測し、user が修正を選んだ。直前の発音のほうがキー数が多く、その余韻が新しいピークの半分を超えるときに限り、発音から最大２秒、ピークを測り直して下げる。すべての発音で測り直す案は、単音の連打で減衰を追い上げるので採らない。この２秒の間は、減衰する音色の単音自身の減衰も追う。最終ミックスのリミッターは、連打や他トラックの加算によるピークを抑える。
