# ADR 0018: 電源設定による音切れ解消を踏まえ、バッファ拡大snippetも維持する

- 状態: 採用。アプリが電源設定を変えない部分は置き換え済み（[ADR 0024](0024-min-processor-state-snippet.md)）
- 決定者: user（1024から4096 framesへ変更するsnippetを付け、FTZ・DAZは有効化しない。電源設定の変更で1024 framesでも音切れが解消した後も、設定に気づかない場合の対処としてsnippetを残す。アプリで電源設定を変えない）
- 関連: [ADR 0016](0016-track-freeze-for-listening.md)、[音声デバイスのバッファサイズ補修](../../patches/uapmd/device-buffer-size/README.md)

## 背景と判断の根拠

実利用projectで音の途切れがあり、userの当初の切り分けではTONE3000のLA-2A使用時に問題が表れた。1024から4096 framesへの変更で改善したため、pluginを使い続けながら途切れを減らす手段として、バッファを拡大するsnippetを用意する判断をした。

FTZ・DAZによる改善も比較した。48 kHz・1024 framesの同じprojectを各60秒再生した計測では、CLAP呼出しにFTZ・DAZを強制してもworkerの処理期限超過が残り、記録された件数は無効時8件、有効時13件だった。対象trackの処理時間の平均・p95にも実質的な改善はなかった。各1回の比較から悪化まで断定せず、今回の対策として採用する根拠が得られなかったと判断する。

この比較はCLAP呼出しの入口と出口で両flagを確認したものであり、plugin内部での一時的な変更やpluginが作るthreadまでは保証しない。FTZ・DAZで改善しなかったことから、denormalが一切関係しないとまでは断定しない。

その後、user環境ではWindowsの詳細な電源設定にある「プロセッサの電源管理」の「最小のプロセッサの状態」を5%から100%へ変更することで、1024 framesのまま音の途切れが解消した。この観測から、今回の途切れをLA-2A単体の問題とする見方を改め、電源設定も関係する現象として扱う。CPU内部の動作やplugin処理との因果関係までは確定していない。

## 決定と理由

今回のuser環境では、バッファを拡大せず電源設定の変更で1024 framesの再生を継続できる。一方、電源設定に気づかない場合や設定を変更しない場合にも対処を選べるよう、1024 framesを基準に4倍の4096 framesへ変更する組込みsnippetを維持する。アプリの既定値を一律に4096へ変更せず、必要なときに既存の音声デバイス再設定APIをscriptから呼ぶ。アプリによる電源設定の自動変更は追加しない。userは、アプリが変更前の値へ戻さずに終わる経路（panicによる終了など）で、変えた設定が残るリスクを想定した。また、userはまずbuffer 4倍でUX検証を進めることを想定した。FTZ・DAZは従来の扱いを維持し、アプリによる強制有効化を通常の再生には導入しない。

4096 framesは音の途切れを改善するために待ち時間を引き受ける選択である。48 kHzで1ブロックの時間は約21.3 msから85.3 msへ、80%のworker処理期限は約17.1 msから68.3 msへ増える。この値はブロック時間であり、デバイスを含む全体の入出力遅延の実測値ではない。

## 結果と制限

電源設定の変更による解消とバッファ拡大による改善は、今回のuser環境・projectでの確認に基づく。すべての環境・plugin・projectでの途切れの解消や、LA-2A自体の処理負荷の解消を保証しない。5%は今回変更前の値であり、すべての環境の既定値とは扱わない。反応速度が必要な演奏では大きいバッファが不利になるため、今回の解消を4096 framesが必須という根拠にはしない。track freezeを試す[ADR 0016](0016-track-freeze-for-listening.md)の選択は維持し、今回のsnippetも追加の選択肢として残す。

計測用のworker診断とFTZ・DAZの観測・実験用guardは、この再生方針に必須ではない。userは証拠を保全したうえでこれらを撤去する方針を選んだ。調査のために各plugin呼出しやtrack処理へ加えた観測負荷を通常の再生に残さないためである。再調査用の診断ソースと生ログはrepository外へ保全し、バッファサイズを指定する既存の再生検証scriptは維持する。ADRには判断の根拠となる比較条件と結果を残す。
